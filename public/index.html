    Three steps, in the order you'd expect
    No accounts, no uploads to a server, no AI guessing what you meant.
    
    
      
      
    1. Add and order
      Drop your clips. The top clip plays first. Drag or use the arrows to change the order.
      2. 
      
    2. Pick the join
      Choose a direct cut or one of seven transitions, and set how long it lasts. The timeline shows exactly where clips overlap.
      3. 
      
    3. Stitch and download
      Stitch encodes the sequence with ffmpeg on your machine — clean frame cuts, not a screen recording. Then download.
      4. 
    
    
  
    

  
    
    
    Eight joins, each named for what it does
    They match FFmpeg's xfade transitions, so the same names work if you move to the command line later.
    
    
    
  
    

  
    
    
    What Manual mode doesn't do yet
    Stated up front so the export never surprises you.
    
    
    
      
    Joins
    One join for the whole sequence
    The join you pick applies between every pair of clips. Different joins per cut are not supported yet.
    
      
    Frame
    Mixed sizes get padded
    The first clip sets the frame. Clips with a different shape are fitted inside it with black bars.
    
      
    Trim
    No per-clip trim
    Each clip plays in full. Trim clips before adding them if you need a shorter cut.
    
    
    
  
    

  
    
    
    Questions
    
    
    
      
    Do my videos get uploaded?
    Only to the Stitch server running on this machine for the ffmpeg encode — then they're deleted. Nothing goes to the cloud.
    
      
    What format do I get?
    MP4 when your browser can record it (recent Chrome, Edge and Safari). Otherwise WebM. The output card shows which one you got.
    
      
    How long does stitching take?
    Export runs through ffmpeg on this machine. A short cut is usually ready in a few seconds — not real-time recording.
    
      
    Is the audio kept?
    Yes. Audio from each clip is carried into the export and crossfades during transitions. The preview stays muted.
